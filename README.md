## Simple Song Player

I made this program so that I (as well as whoever wishes to play a song of their liking) can test out my buzzers [hardware], but this directory also has a pure software player where to get your song played at runtime, you'd just need to execute code, whilst also having an embedded programming side where you get to play around with your buzzers and play around with the code to your liking.

## This is just a blueprint, to which the blueprint was made so that it wouldn't be overcomplicated as well as be compatible to operating systems outside of just windows.
