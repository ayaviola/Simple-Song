## Simple Song Player

I made this program as a nice and friendly way to test out buzzer hardware, but this directory also includes a pure software player where you run and enjoy whatever song you created right at runtime! If you have a knack and enjoy embedded programming, you can also dive into the code and experiment with your own buzzers.

-----

#### _Simple Blueprints for Simple Tasks!_
To keep things accessible, I made sure to design this directory as a clean blueprint that is free of redundancies/unecessary complexities and built to work across various operating systems outside of just Windows.

Have fun tinkering!
